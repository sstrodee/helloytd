helloytd 1.0.0 • Windows x64

1. Распаковать архив целиком в папку с доступом на запись.
2. Запустить helloytd.exe. Python уже включён в архив.
3. Вставить ссылку, выбрать формат и нажать «скачать».

Нужен FFmpeg и один JavaScript-движок (Node.js или Deno).
Команды для установки через Windows Package Manager:
  winget install Gyan.FFmpeg
  winget install DenoLand.Deno

Внутри portable-папки:
  app\       код приложения
  runtime\   встроенный Python и библиотеки
  assets\    значки и шрифты
  data\      настройки, история и кэш после первого запуска

В папке без доступа на запись данные сохраняются в %APPDATA%\helloytd.
Для переноса настроек можно скопировать папку data после закрытия программы.
Скачанные файлы остаются в выбранной папке.

Если форматы YouTube изменились, в настройках есть «обновить yt-dlp».
После обновления требуется перезапуск.

Архив включает Qt и PySide6 под LGPL 3. Сведения о библиотеках,
исходниках и лицензиях приведены в THIRD_PARTY_NOTICES.md.
