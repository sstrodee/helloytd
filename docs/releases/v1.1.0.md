## English

helloytd is now available in English and Russian in the same Windows portable build. The app follows the Windows display language on the first launch. **Settings → Language** selects a language manually. Restart to apply the change.

Download **helloytd-1.1.0-windows-x64.zip**, extract the entire archive, and open `helloytd.exe`. Python is included. FFmpeg and Node.js or Deno are installed separately.

## Русский

Английский и русский интерфейсы теперь доступны в одной portable-сборке для Windows. При первом запуске приложение подхватывает язык Windows. В «Настройки» → «Язык» можно выбрать язык вручную. Изменение применяется после перезапуска.

Для запуска достаточно распаковать **helloytd-1.1.0-windows-x64.zip** целиком и открыть `helloytd.exe`. Python уже внутри. FFmpeg и Node.js или Deno устанавливаются отдельно.
