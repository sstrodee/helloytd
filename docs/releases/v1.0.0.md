## helloytd 1.0.0

Первый публичный выпуск для Windows x64. В одном окне можно сохранить видео, звуковую дорожку или выбранный отрезок.

### Скачать и запустить

1. Скачать **helloytd-1.0.0-windows-x64.zip** из списка файлов этого выпуска.
2. Распаковать архив целиком и запустить `helloytd.exe`.
3. Если приложение сообщает об отсутствующих компонентах, установить FFmpeg и Node.js или Deno.

В ZIP включён Python и библиотеки приложения. Файл `.sha256` содержит контрольную сумму архива. [Лицензии и исходники сторонних компонентов](https://github.com/sstrodee/helloytd/blob/v1.0.0/THIRD_PARTY_NOTICES.md).

### В этом выпуске

- Видео до 4K, аудио MP3 и M4A с обложками.
- Фрагменты по таймкодам до 1080p.
- Плейлисты, субтитры, история и очередь загрузок.
- Настройка маршрута к YouTube и обновление yt-dlp из приложения.

### Известные ограничения

- Остановка фрагмента может занять время, пока активен FFmpeg.
- Отдельный SRT может сохранить таймкоды полного ролика при скачивании фрагмента.
